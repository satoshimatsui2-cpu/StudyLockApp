EikenForSlacker プライバシーポリシー

最終更新日：2025年5月22日

EikenForSlacker（以下「本アプリ」）は、個人の学習習慣サポートおよび保護者による見守り対応を実現するための学習管理アプリです。 本プライバシーポリシーでは、本アプリが取り扱う情報、その利用目的、管理方法について説明します。

1. 収集する情報と利用目的

本アプリは、サービスの提供にあたり以下の情報を取得・利用します。

  • アカウント情報： Firebase Authenticationによるユーザー識別子。
  • 学習データ： 学習履歴、正解・不正解、学習回数、習熟度、獲得・使用ポイント、発音チェックの結果、バッジ獲得状況。
  • 見守り情報： ペアリングされた親端末への学習進捗や利用状況の共有。
  • デバイス情報： 通知用トークン（FCMトークン）、プッシュ通知の配信に使用。
  • アクセシビリティ状態： アクセシビリティサービスの有効・無効状態の検知。

2. AccessibilityService API の利用について

本アプリは、ユーザーまたは保護者が設定した利用ルールを維持し、学習習慣をサポートするために「アクセシビリティ権限」を使用します。

利用目的：

  • 学習ポイント不足時に、あらかじめ指定された制限対象アプリの起動を検知し、学習画面を表示するため。
  • 制限機能に関連するシステム設定画面へのアクセスを検知し、設定の意図しない変更を防ぐため。
  • 保護者見守り機能において、制限状態の変更を通知するため。

収集・共有しない情報：

本アプリは、アクセシビリティ権限を通じて、以下の機密情報を収集、保存、または共有することは一切ありません。

  • キーボード入力内容（パスワード、検索語句など）
  • メッセージ本文（メール、チャット内容など）
  • 通話内容、連絡先情報、個人間の会話履歴
  • 画面上の個人情報やプライベートな画像

3. マイク権限（録音）の利用について

本アプリは、英語の発音チェック機能において音声を認識するためにマイクを利用します。

  • 利用範囲： 発音チェックの録音ボタンが押されている間のみ音声を処理します。
  • 取り扱い： 本アプリは、音声データそのものを本アプリのサーバーへ保存・送信することはありません。
  • 保存データ： 音声から解析されたテキスト結果および判定結果のみを学習記録として保存します。

4. 外部サービスの利用について

本アプリは、Google Firebase（Authentication, Firestore, Cloud Functions, Messaging）を利用してデータの安全な保存とプッシュ通知の提供を行っています。
